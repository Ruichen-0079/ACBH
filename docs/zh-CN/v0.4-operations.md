# ACBH v0.4.0-alpha1 运维说明

## 世界差量备份

自动接管与 Desktop 一键开停服仅同步 **世界目录**（`level-name` 及额外 `world-root`），不再自动拉取 `server-pack` 或 `admin-state`。

- 对象存储：`groups/<groupId>/objects/sha256/<prefix>/<hash>`
- 快照清单：`groups/<groupId>/world-backups/<snapshotId>/manifest.json`
- 本地索引：`<AppData>/world-backup/index.json`

### Agent CLI

```bash
acbh-agent world-backup create
acbh-agent world-backup create --online
acbh-agent world-backup status
acbh-agent world-backup list
acbh-agent world-backup restore latest
acbh-agent world-backup pin <id>
acbh-agent world-backup gc --dry-run
```

### Desktop GUI

主界面新增 **世界差量备份** 区域，可查看最新快照指标并触发备份/恢复/固定/删除操作。长时间任务在后台执行，不阻塞 UI 线程。

## Coordinator 事务式升级

生产布局：

```text
/opt/acbh/
├─ .env
├─ storage/ data/ logs/ packages/
├─ releases/<version>/
└─ current -> releases/<version>
```

### 升级

```bash
sudo bash acbh-vps-upgrade.sh /path/to/bundle
sudo bash acbh-vps-upgrade.sh /path/to/bundle --dry-run
```

升级前验证 `VERSION`、`SHA256SUMS`、`dist/index.js`、Node 20+、磁盘空间；使用 `flock /opt/acbh/.upgrade.lock`。失败时自动回滚 `current` 并尽可能恢复 state 备份。

### 回滚

```bash
sudo bash acbh-vps-rollback.sh
sudo bash acbh-vps-rollback.sh v0.3.5-hotfix1
```

### 状态

```bash
sudo bash acbh-vps-status.sh
```

升级报告：`/opt/acbh/logs/upgrades/<timestamp>-<version>.json`

## 保留的 v0.3.5 Hotfix 能力

Public Relay（`listGroups()` / `PublicGroupState`）与 Desktop Hotfix 面板行为保持不变；v0.4 自动流程改为世界专用备份模型。
