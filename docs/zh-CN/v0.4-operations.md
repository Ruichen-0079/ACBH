# ACBH v0.4.0-alpha2 运维说明

## 世界差量备份

自动接管与 Desktop 一键开停服仅同步 **世界目录**（`level-name` 及额外 `world-root`），不再自动拉取 `server-pack` 或 `admin-state`。

- 对象存储：`groups/<groupId>/objects/sha256/<prefix>/<hash>`
- 快照清单：`groups/<groupId>/world-backups/<snapshotId>/manifest.json`
- 本地索引：`<AppData>/world-backup/index.json`

### 在线一致备份

`--online` 在 RCON `save-off` 与 `save-all flush` 之后，将世界文件复制到
`<AppData>/world-backup/transactions/<transactionId>/staging/`，完成后再执行 `save-on`。
快照哈希与上传仅读取 staging，不读取恢复保存后的活跃世界。任何失败路径都会尝试 `save-on`。

### Agent CLI

```bash
acbh-agent world-backup create
acbh-agent world-backup create --online
acbh-agent world-backup status
acbh-agent world-backup list
acbh-agent world-backup restore latest
acbh-agent world-backup pin <id>
acbh-agent world-backup gc --dry-run
```

### Desktop GUI

主界面新增 **世界差量备份** 区域，可查看最新快照指标并触发备份/恢复/固定/删除操作。长时间任务在后台执行，不阻塞 UI 线程。

### 成员与邀请码（Windows GUI）

主界面 **成员与邀请** 区域（配置完成后仍可用）：

- **生成邀请码**：Owner 设备可设置有效期（分钟）与是否单次使用；明文仅在结果对话框显示一次。
- **查看邀请码**：打开管理窗口，列表默认掩码 Invite ID，可按状态筛选识别（可用 / 已使用 / 已过期 / 已撤销）。
- **撤销邀请码**：选中后确认撤销，操作不可逆。
- **加入已有 Group**：向导中输入邀请码（默认遮罩）；GUI 通过 `ACBH_INVITE_CODE` 环境变量调用 Agent，不把邀请码写入命令行或日志。

说明：邀请码用于邀请**另一台电脑**加入 ACBH Group 并成为候选 Host，不是 Minecraft 玩家白名单。

CLI 等效命令（仍可用）：

```bash
acbh-agent desktop setup create-invite --expires-seconds 1800 --one-time
acbh-agent desktop setup list-invites
acbh-agent desktop setup revoke-invite --invite-id <id>
# 加入时可用环境变量避免 argv 暴露：
set ACBH_INVITE_CODE=ACBH-XXXXXX-XXXXXX
acbh-agent desktop setup join-group --coordinator-url http://host:6121 --display-name 昵称
```

### Minecraft 启动等待（`server.startTimeout`）

`config.yaml` 中 `server.startTimeout` 控制 `start-auto` 等待本地 Minecraft 端口就绪的最长时间：

- 默认：`120s`
- 最小：`10s`
- 旧配置未设置时自动使用默认值

GUI 状态栏会显示当前启动等待时长。整合包冷启动较慢时建议设为 `120s`～`180s`。

## Coordinator 事务式升级

生产布局：

```text
/opt/acbh/
├─ .env
├─ storage/ data/ logs/ packages/
├─ releases/<version>/
└─ current -> releases/<version>
```

### 升级

```bash
sudo bash acbh-vps-upgrade.sh /path/to/bundle
sudo bash acbh-vps-upgrade.sh /path/to/bundle --dry-run
```

升级前验证 `VERSION`、`SHA256SUMS`、`dist/index.js`、Node 20+、磁盘空间；使用 `flock /opt/acbh/.upgrade.lock`。失败时自动回滚 `current` 并尽可能恢复 state 备份。

### 回滚

```bash
sudo bash acbh-vps-rollback.sh
sudo bash acbh-vps-rollback.sh v0.3.5-hotfix1
```

### 状态

```bash
sudo bash acbh-vps-status.sh
```

升级报告：`/opt/acbh/logs/upgrades/<timestamp>-<version>.json`

## 保留的 v0.3.5 Hotfix 能力

Public Relay（`listGroups()` / `PublicGroupState`）与 Desktop Hotfix 面板行为保持不变；v0.4 自动流程改为世界专用备份模型。
