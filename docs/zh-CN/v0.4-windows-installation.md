# ACBH v0.4 Windows 安装、升级、卸载与回滚

## 产品边界

ACBH v0.4 只探测 `127.0.0.1:<自定义端口>`、维护受管理的 FRP 公网中转，并展示状态与脱敏日志。Minecraft 服务器始终由用户手动启动和停止。ACBH 不读取 `server.properties`，不启动或终止 Java，也不管理世界、模组、插件或服务端文件。

## 安装版

1. 运行 `ACBH-<版本>-windows-x64-setup.exe`，需要管理员权限。
2. 程序安装到 `%ProgramFiles%\ACBH`。
3. Windows 服务 `ACBHAgent` 使用本地系统账户自动启动。
4. 配置、期望状态和有限日志写入 `%ProgramData%\ACBH`。普通用户不能直接读取其中的 Token；配置通过只绑定 `127.0.0.1:6130` 的本地 API 写入。
5. 从开始菜单或桌面打开“ACBH 公网中转”。默认浏览器只是薄界面，关闭页面不会停止服务或 frpc。

安装包不修改 Windows 防火墙，不安装 Node.js、Java、Minecraft 或系统级 frpc，也不依赖 PATH 和当前工作目录。

## Portable ZIP

1. 将 ZIP 完整解压到可写目录，路径可以包含中文或空格。
2. 双击 `acbh-launcher.exe`。Launcher 会在当前目录的 `data` 子目录保存 portable 状态，并启动同目录的 `acbh-agent.exe` 与经过校验的 `frpc.exe`。
3. Portable 模式不是系统服务；注销用户会停止它。需要开机无人值守运行时应使用 Setup EXE。

不要只复制单个 EXE；`acbh-agent.exe`、`acbh-launcher.exe`、`frpc.exe`、`portable.flag` 和许可证文件属于同一个发行包。

## 覆盖升级

运行新版本 Setup EXE 并选择相同安装目录。安装器会停止 `ACBHAgent`、替换只读程序文件、更新服务命令并重新启动服务。`%ProgramData%\ACBH` 中的配置和期望中转状态会保留。升级过程不会停止或接管 Minecraft/Java。

升级前建议保存旧 Setup EXE、ZIP、manifest 和 `SHA256SUMS`，并核对新文件哈希。

## 卸载

从 Windows“应用和功能”卸载 ACBH。卸载器会停止并删除 `ACBHAgent`，删除 `%ProgramFiles%\ACBH` 中的程序文件，但默认保留 `%ProgramData%\ACBH`，避免误删 Token、配置和诊断记录。

确认不再需要数据后，可由管理员手动删除 `%ProgramData%\ACBH`。卸载器不会删除 Minecraft、Java、其他 frpc、VPS 服务或防火墙规则。

## 回滚

1. 使用当前版本卸载器卸载程序文件；保留 `%ProgramData%\ACBH`。
2. 安装已保存的上一版 Setup EXE。
3. 核对该安装器的 SHA-256 与上一版 `SHA256SUMS` 一致。
4. 打开本地页面检查配置，并手动执行“保存并启动”。

若旧版本不兼容新配置，先备份 `%ProgramData%\ACBH`，再停止 `ACBHAgent`，将该目录改名后启动旧版本。不要把 v0.3 的 session、lease、relay_state、remote-public 或 Desktop 状态复制进 v0.4 数据目录。

## 安全说明

- “Access Token”只指 ACBH 控制面 Token，不是 PEM、SSH 密码或 VPS 私钥。
- API 和 UI 不会回显 Token 原文。
- 日志和诊断包不包含 Token、玩家 IP、Agent 来源地址、PEM/SSH 信息或带秘密的命令行。
- Agent 只停止由其持久化身份明确认领的 frpc，不会按进程名或端口批量终止进程。
