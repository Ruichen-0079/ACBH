# Windows GUI：成员与邀请码

## 入口

完成四步配置后，主界面 **成员与邀请** 区域始终可用：

- 当前 Group 名称或 ID
- 本机身份（owner / member + Host ID）
- 是否可管理邀请码（仅 owner）
- 生成邀请码 / 查看邀请码 / 刷新

## 生成邀请码

1. 点击 **生成邀请码**（仅 owner）。
2. 在对话框设置 **有效期（分钟）** 与 **是否单次使用**。
3. 确认后后台执行 `desktop setup create-invite`，窗口不冻结。
4. 成功后在独立对话框显示邀请码明文（**只显示一次**）。
5. 可 **复制邀请码** 或 **复制完整邀请信息**（含当前配置的 Coordinator 地址）。

当前 API 限制：不支持备注名称、自定义最大使用次数（除单次/可重复外）。

## 查看与撤销

**查看邀请码** 打开管理窗口：

| 列 | 说明 |
| --- | --- |
| Invite ID | 掩码显示，非完整邀请码 |
| 状态 | 可用 / 已使用 / 已过期 / 已撤销 |
| 创建 / 过期 | ISO 时间 |
| 使用限制 | 单次使用 或 可重复使用 |

选中一行后点 **撤销邀请码**，确认后不可逆。

## 加入已有 Group

在 **四步配置 → 第 1 步**：

1. 填写公网 Coordinator（第 2 步可先检查，也可先填 host 再检查）。
2. 在邀请码框粘贴邀请码（默认密码式遮罩，可点 **显示** 临时查看）。
3. 点击 **加入已有 Group**。

成功后 GUI 会清空邀请码输入框与内存中的临时变量，并刷新 Group 状态。日志中不会出现邀请码明文。

## 安全约定

- 邀请码不会写入普通日志区、长期日志文件、`config.yaml` 或错误弹窗中的完整 JSON。
- 列表与日志中的 `ACBH-XXXXXX-XXXXXX` 会被自动掩码。
- 复制后提示：请勿发送给不受信任的人。
- 邀请的是 **ACBH Group 成员/Host**，不是 Minecraft 游戏内玩家。
